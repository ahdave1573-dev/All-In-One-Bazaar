# All-In-One Bazaar 🛒

A full-stack, responsive E-commerce platform built with PHP and MySQL. This web application provides a seamless shopping experience for users and a robust management panel for administrators.

---

## 🚀 Key Features

### 👤 User Panel
* **Authentication:** Secure registration and login gateway.
* **Product Catalog:** Advanced search functionality and category-wise browsing.
* **Shopping Cart:** Seamless cart updates powered by AJAX for a faster UI experience.
* **Wishlist Management:** Backend logic to save and manage favorite items.
* **Order Tracking:** Real-time order processing and purchase history verification.
* **Profile Management:** Secure user dashboard with password change utility.

### 🛡️ Admin Panel
* **Product Management:** Complete CRUD system to add, edit, and delete products.
* **Category Control:** Dynamic management of product categories and themes.
* **Order Tracking:** Centralized dashboard to track, update, and manage consumer orders.
* **Data Utility:** Built-in scripts for product data export and color migrations.

---

## 🛠️ Technology Stack

* **Frontend:** HTML5, CSS3, JavaScript, AJAX
* **Backend:** PHP (Object-Oriented approaches & procedural scripting)
* **Database:** MySQL (Structured Relational Database Management)

---

## 📂 Database Setup
The complete database structure and sample datasets are available in the repository as `all_in_one_bazaar.sql`. Import this file into your local phpMyAdmin server to initialize the platform.
